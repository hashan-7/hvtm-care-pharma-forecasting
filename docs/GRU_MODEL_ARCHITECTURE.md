# Gated Recurrent Unit (GRU) Forecasting Architecture

## 1. Overview & Theoretical Motivation
Pharmaceutical demand exhibits pronounced non-linear patterns, strong multi-month autocorrelation, and temporal dependency influenced by seasonal consumption, prescription replenishment cycles, and currency rate shifts. Traditional feedforward networks and static regressors treat consecutive monthly timeframes as independent identically distributed (i.i.d.) observations, failing to capture historical sequential context.

To resolve this limitation, a specialized **Gated Recurrent Unit (GRU)** sequential neural network was designed and trained to model temporal demand trajectories. The GRU variant was selected over standard Recurrent Neural Networks (RNN) and Long Short-Term Memory (LSTM) due to its computational efficiency, reduced parameter count, and resilience against vanishing/exploding gradient phenomena during backpropagation through time (BPTT).

---

## 2. Mathematical Formulation
At timeframe $t$, given the scaled input feature vector $x_t \in \mathbb{R}^{d}$ and previous hidden state $h_{t-1} \in \mathbb{R}^{h}$, the GRU network performs sequential state transitions using dual gating mechanisms:

### 2.1 Update Gate ($z_t$)
Controls the degree to which previous historical state information is passed forward into the current prediction timeframe:
$$z_t = \sigma(W_z x_t + U_z h_{t-1} + b_z)$$
Where $\sigma(x) = \frac{1}{1 + e^{-x}}$ denotes the logistic sigmoid activation.

### 2.2 Reset Gate ($r_t$)
Determines how much of the past memory state should be ignored or reset when computing candidate hidden representations:
$$r_t = \sigma(W_r x_t + U_r h_{t-1} + b_r)$$

### 2.3 Candidate Hidden State ($\tilde{h}_t$)
Calculates candidate activation incorporating gated historical memory:
$$\tilde{h}_t = \tanh(W_h x_t + U_h (r_t \odot h_{t-1}) + b_h)$$
Where $\odot$ represents the Hadamard element-wise product.

### 2.4 Final Hidden State ($h_t$)
Combines previous memory state with newly computed candidate state:
$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

## 3. Neural Network Architecture Specification

The deep learning forecasting architecture is constructed as a multi-stage sequential topology implemented in TensorFlow/Keras:

```text
Input Layer: Tensor (batch_size, timesteps=1, features=38)
      │
      ▼
GRU Recurrent Layer (64 Hidden Units, return_sequences=False)
      │
      ▼
Dropout Regularization Layer (rate = 0.20)
      │
      ▼
Dense Feedforward Layer (32 Units, Activation = ReLU)
      │
      ▼
Dense Output Layer (1 Unit, Activation = Sigmoid / Linear Projection)
```

### Layer Details:
1. **Input Representation:** 3D sequence tensor shaped `(batch_size, 1, 38)` containing normalized cyclic temporal features, lag demand features, rolling means, and macroeconomic indicators.
2. **Primary Recurrent Layer:** 64 gated units capturing sequential dynamics and inter-feature interactions across temporal windows.
3. **Dropout Regularization:** 20% dropout probability applied between recurrent units and dense projection layers to prevent co-adaptation of feature detectors and mitigate overfitting.
4. **Intermediate Representation Layer:** 32 hidden units with Rectified Linear Unit ($\text{ReLU}(x) = \max(0, x)$) activation for non-linear feature transformation.
5. **Output Prediction Layer:** Single unit producing continuous scaled demand forecasts mapped to the inverse transformation pipeline.

## 4. Hyperparameter Configuration & Training Protocol

| Hyperparameter | Configuration Value | Optimization Rationale |
| :--- | :--- | :--- |
| **Optimizer** | Adam ($\beta_1=0.9, \beta_2=0.999$) | Adaptive learning rate per parameter |
| **Initial Learning Rate** | $1 \times 10^{-3}$ (0.001) | Fast initial convergence without gradient divergence |
| **Loss Function** | Mean Squared Error (MSE) | Penalizes large forecasting deviations heavily |
| **Batch Size** | 32 | Balance between gradient variance and memory cache throughput |
| **Maximum Epochs** | 100 | Sufficient capacity for convergence |
| **Early Stopping** | `monitor='val_loss', patience=10` | Automatically terminates training upon validation plateau |
| **Weight Restoration** | `restore_best_weights=True` | Retains optimal checkpoint parameters with lowest validation loss |

## 5. Integration into the NeuroStack Meta-Learner
The individual sequential forecast generated by the GRU model ($p_{\text{GRU}}$) serves as a primary Level-0 meta-feature:
```text
Stacking Vector = [p_LR, p_RF, p_XGB, p_BiLSTM, p_GRU]
                           │
                           ▼
              NeuroStack Meta-Learner Layer
                           │
                           ▼
               Final Unified Demand Estimate
```
By combining the temporal sequence memory of the GRU with tree-based ensembles (Random Forest, XGBoost) and bidirectional recurrent models (BiLSTM), the system achieves balanced variance reduction and robust generalization across all 30 pharmaceutical product profiles.
