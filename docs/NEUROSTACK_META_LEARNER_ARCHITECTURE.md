# NeuroStack Meta-Learner Hybrid Stacking Architecture

## 1. Executive Summary & Stacking Paradigm
Predicting pharmaceutical demand under macroeconomic crisis, currency fluctuations, and localized supply disruptions is inherently fraught with modeling trade-offs:
- **Linear Models (LR):** Excel at establishing monotonic trend lines but fail under non-linear demand shifts.
- **Ensemble Decision Trees (Random Forest, XGBoost):** Excel at tabular interactions and feature thresholding but lack sequential memory.
- **Deep Recurrent Networks (GRU, BiLSTM):** Excel at long-term temporal inertia and sequential patterns but are susceptible to noise in small sample regimes.

To resolve these trade-offs, **NeuroStack** implements a two-tier **Hybrid Stacking Ensemble** architecture based on Wolpert's stacked generalization theory. NeuroStack treats the diverse predictions of five heterogeneous Level-0 models as meta-features, learning an optimal, non-linear consensus mapping that consistently outperforms any individual constituent predictor.

## 2. Mathematical Framework & Stacking Topology

```

                  │          38-Dimensional Input Vector         │
                  └──────────────────────┬───────────────────────┘
                                         │
                 ┌───────────────────────┼───────────────────────┐
                 │                       │                       │
                 ▼                       ▼                       ▼

                 │                       │                       │

                 │                 [ Deep Recurrent ]            │
                 │            ┌──────────┴──────────┐            │
                 │            ▼                     ▼            │
                 │        [ GRU Net ]          [ BiLSTM ]        │

                 └────────────┼──────────┬──────────┼────────────┘
                              │          │          │
                              ▼          ▼          ▼
            Level-0 Prediction Meta-Vector: S = [p_LR, p_RF, p_XGB, p_BiLSTM, p_GRU]
                                         │
                                         ▼
                 ┌──────────────────────────────────────────────┐
                 │       Level-1 NeuroStack Neural Engine       │

                 └──────────────────────┬───────────────────────┘
                                         │
                                         ▼
                           Final Stabilized Demand: ŷ
```

### 2.1 Level-0 Base Learners Pool
The continuous predictions generated by all five base learners are extracted and concatenated into a 5-dimensional meta-feature vector $S$:
$$S = \begin{bmatrix} p_{\text{LR}}(x) & p_{\text{RF}}(x) & p_{\text{XGB}}(x) & p_{\text{BiLSTM}}(x) & p_{\text{GRU}}(x) \end{bmatrix}^T \in \mathbb{R}^5$$

### 2.2 Level-1 Meta-Learner Function
The meta-learner $g_{\theta}(S)$ approximates the conditional expectation of actual demand $y$ given the base learner vector $S$:
$$\hat{y} = g_{\theta}(S) = W_3 \cdot \sigma\left(W_2 \cdot \sigma(W_1 S + b_1) + b_2\right) + b_3$$

Where $\sigma(\cdot)$ is the ReLU activation function and $\theta = \{W_1, W_2, W_3, b_1, b_2, b_3\}$ denotes trainable network parameters.

## 3. Training Protocol & Leakage Prevention

### Out-of-Fold (OOF) Stacking
To eliminate data leakage and prevent the meta-learner from overfitting to overly optimistic training predictions:
1. The training partition ($\mathcal{D}_{\text{train}}$) is divided into $K = 5$ sequential temporal folds.
2. For each fold $k \in \{1, \dots, K\}$, base learners are trained strictly on the remaining $K - 1$ folds and evaluate the held-out fold $k$.
3. Held-out predictions from all $K$ folds are assembled to form the out-of-fold training matrix $S_{\text{OOF}}$.
4. The Level-1 NeuroStack meta-network is trained exclusively on $S_{\text{OOF}}$, ensuring its learned weights represent real-world generalization error rather than memorized training labels.

## 4. Empirical Performance Benchmarking

Across the 13-month unseen evaluation period (January 2025 – January 2026), NeuroStack demonstrated clear superiority over all individual base learners:

| Architecture | Model Class | RMSE (Units) | MAE (Units) | $R^2$ Score |
| :--- | :--- | :--- | :--- | :--- |
| **Linear Regression** | Baseline Statistical | 482.16 | 321.40 | 0.724 |
| **Random Forest** | Bagged Decision Trees | 317.25 | 198.80 | 0.881 |
| **XGBoost** | Gradient Boosted Trees | 294.10 | 182.35 | 0.898 |
| **GRU** | Recurrent Neural Net | 308.45 | 191.12 | 0.887 |
| **BiLSTM** | Bidirectional Recurrent Net | 289.70 | 179.60 | 0.901 |
| **NeuroStack (Ensemble)** | **Meta-Learner Stacking** | **241.30** | **148.95** | **0.932** |

### Key Observations:
- **Error Reduction:** NeuroStack reduced Root Mean Squared Error by **16.7%** compared to the strongest individual base learner (BiLSTM) and **49.9%** compared to Linear Regression.
- **Shock Resilience:** When sudden macroeconomic foreign exchange fluctuations impacted imported medication prices, individual sequential models slightly lagged while decision trees over-corrected; NeuroStack dynamically balanced these outputs, achieving smooth and realistic supply forecasts.

## 5. Runtime Inference Engine Orchestration (`backend/engine_logic.py`)
At production serving time, `engine_logic.py` executes an orchestrated inference pipeline:
1. **Parallel Base Inference:** The 38-feature standardized vector is evaluated through `xgboost_model.pkl`, `optimized_rf_model.pkl`, `linear_regression_model.pkl`, `GRU_model.h5`, and `BiLSTM_model.h5`.
2. **Meta-Vector Aggregation:** Predictions are stacked into matrix $S$.
3. **NeuroStack Forward Pass:** Evaluated through `NeuroStack_MetaLearner.h5` (with an automated fallback to `NeuroStack_MetaLearner.pkl`).
4. **Inverse Scaling & Constraint Enforcement:** Scaled output is converted back into clinical units via `scaler_y.inverse_transform()`, applying non-negativity clipping ($\hat{y} \ge 0$).
