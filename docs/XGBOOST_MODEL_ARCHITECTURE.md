# XGBoost Gradient Boosted Decision Trees Architecture

## 1. Overview & Theoretical Motivation
Pharmaceutical demand exhibits intricate, non-linear relationships across tabular features such as opening inventory, lead time, closing stock ratios, and macroeconomic factors like currency exchange rates. While linear models fail to capture non-linear feature interactions and deep recurrent networks require substantial sequential history, **Extreme Gradient Boosting (XGBoost)** excels at structured tabular prediction.

In the HVTM CARE forecasting engine, XGBoost serves as a high-performance Level-0 tabular base learner within the **NeuroStack** meta-learner ensemble, providing sharp decision boundaries and robust resistance to feature multicollinearity.

---

## 2. Mathematical Formulation & Optimization

XGBoost minimizes a regularized objective function combining convex loss with an explicit tree complexity penalty:

$$\mathcal{L}^{(t)} = \sum_{i=1}^{n} l\left(y_i, \hat{y}_i^{(t-1)} + f_t(x_i)\right) + \Omega(f_t)$$

Where the regularization term $\Omega(f_t)$ penalizes model complexity to mitigate overfitting:
$$\Omega(f_t) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^{T} w_j^2$$

- $T$: Total number of terminal leaves in tree $f_t$
- $w$: Vector of leaf weights
- $\gamma$: Complexity parameter controlling leaf node splitting threshold
- $\lambda$: $L_2$ regularization weight penalizing extreme leaf values

### Second-Order Taylor Approximation
To optimize the objective function rapidly, XGBoost expands the loss using second-order gradients:
$$\mathcal{L}^{(t)} \approx \sum_{i=1}^{n} \left[ l(y_i, \hat{y}_i^{(t-1)}) + g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) \right] + \Omega(f_t)$$

Where first and second-order statistics are defined as:
$$g_i = \partial_{\hat{y}^{(t-1)}} l(y_i, \hat{y}^{(t-1)}) \quad \text{and} \quad h_i = \partial_{\hat{y}^{(t-1)}}^2 l(y_i, \hat{y}^{(t-1)})$$

## 3. Hyperparameter Specification & Training Topology

The gradient boosted regressor is configured with deep tree capacity and stochastic subsampling:

| Hyperparameter | Value | Technical Rationale |
| :--- | :--- | :--- |
| **`n_estimators`** | `500` | Ample boosting iterations to capture subtle non-linear demand shifts |
| **`learning_rate` ($\eta$)** | `0.03` | Conservative shrinkage rate ensuring stable stochastic convergence |
| **`max_depth`** | `10` | Permits higher-order feature interactions across 38 input dimensions |
| **`subsample`** | `0.80` | Randomly samples 80% of training records per tree to reduce variance |
| **`colsample_bytree`** | `0.80` | Randomly samples 80% of features per tree split, preventing single-feature dominance |
| **`objective`** | `reg:squarederror` | Minimizes quadratic forecasting error across drug demand distributions |

## 5. NeuroStack Ensemble Contribution
The continuous predictions generated by XGBoost ($p_{\text{XGB}}$) are extracted and combined into the Level-1 meta-feature vector:
$$S = \begin{bmatrix} p_{\text{LR}} & p_{\text{RF}} & p_{\text{XGB}} & p_{\text{BiLSTM}} & p_{\text{GRU}} \end{bmatrix}$$

XGBoost contributes significantly to the final meta-prediction, particularly during periods of volatile macroeconomic shifts where tree-based feature splitting on `USD_Rate` and `Lead_Time` provides superior accuracy over purely sequential models.
