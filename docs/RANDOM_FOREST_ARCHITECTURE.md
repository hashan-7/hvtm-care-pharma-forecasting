# Random Forest Regressor & Hyperparameter Optimization Architecture

## 1. Overview & Theoretical Motivation
In pharmaceutical demand forecasting, tabular sales and inventory data frequently exhibit non-linear patterns, structural shifts, and complex feature interactions that single parametric models cannot capture. 

**Random Forest (RF)** is an ensemble learning method based on bootstrap aggregation (Bagging) of randomized decision trees. In the HVTM CARE prediction architecture, Random Forest serves as a foundational Level-0 tabular regressor in the **NeuroStack** meta-learner ensemble, providing high generalization accuracy and strong robustness against sample variance and outliers.

---

## 2. Mathematical Formulation & Ensembling Mechanics

### 2.1 Bootstrap Aggregation (Bagging)
Given training dataset $\mathcal{D} = \{(x_1, y_1), \dots, (x_n, y_n)\}$, Random Forest constructs $B$ distinct decision trees:
1. For each tree $b = 1, \dots, B$, draw a bootstrap sample $\mathcal{D}_b$ of size $n$ with replacement from $\mathcal{D}$.
2. At each node of tree $T_b$, randomly select $m$ candidate features out of total features $p$ (where typically $m \approx \sqrt{p}$ or $p/3$ for regression).
3. Split the node using the feature that minimizes the Mean Squared Error (MSE) criterion:
   $$\text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$

### 2.2 Ensemble Prediction
The continuous forecast is generated by computing the unweighted average across all $B$ randomized trees:
$$\hat{f}_{\text{RF}}(x) = \frac{1}{B} \sum_{b=1}^{B} T_b(x)$$

### 2.3 Out-of-Bag (OOB) Generalization
Samples omitted from each bootstrap draw ($\approx 36.8\%$ of records) are used for continuous out-of-bag validation, preventing overfitting without requiring separate test holdouts during tree growth.

## 3. Hyperparameter Specification & Grid Search Optimization

Extensive hyperparameter exploration was conducted via cross-validated Grid Search (`Hyperparameter_Tuning.ipynb`) to determine the optimal configuration:

| Hyperparameter | Baseline Value | Optimized Value | Technical Rationale |
| :--- | :--- | :--- | :--- |
| **`n_estimators`** | `100` | `300` | Reduces variance and stabilizes ensemble predictions across rare drug categories. |
| **`max_depth`** | `None` (unbounded) | `16` | Constrains tree depth to prevent memorization of historical noise and outliers. |
| **`min_samples_split`** | `2` | `5` | Ensures splits occur only on statistically significant inventory sample sizes. |
| **`min_samples_leaf`** | `1` | `2` | Smooths leaf predictions to prevent abrupt forecast spikes. |
| **`max_features`** | `1.0` (all) | `'sqrt'` | Induces diversity across decision trees, decorrelating individual estimators. |
| **`criterion`** | `squared_error` | `squared_error` | Penalizes larger forecasting deviations across critical pharmaceutical supplies. |

## 4. Linear Regression Baseline Comparison

To benchmark non-linear ensemble performance, a standard **Multiple Linear Regression (LR)** model was trained on the identical 38-feature matrix:

$$\hat{y}_{\text{LR}} = \beta_0 + \sum_{j=1}^{p} \beta_j x_j + \epsilon$$

### Key Findings
- Linear Regression achieved reasonable baseline accuracy on steady maintenance medications (e.g., Metformin, Enalapril), but failed to capture seasonal surge dynamics and price elasticity shocks.
- The Optimized Random Forest model reduced Root Mean Squared Error (RMSE) by **34.2%** compared to the baseline Linear Regressor, justifying its inclusion as a core Level-0 learner.

## 5. Feature Importance Analysis & NeuroStack Role
Mean Decrease in Impurity (MDI) analysis revealed that the top predictors of demand are:
1. `Issued_Qty_Lag1` (Previous month consumption volume)
2. `Closing_Stock_Lag1` (Stock availability buffer)
3. `Rolling_Mean_3M` (Quarterly rolling consumption momentum)
4. `USD_Rate` (Macroeconomic import cost indicator)

The output predictions from the Random Forest model ($p_{\text{RF}}$) and Linear Regression ($p_{\text{LR}}$) are piped directly into the Level-1 **NeuroStack Meta-Learner**:
$$S = \begin{bmatrix} p_{\text{LR}} & p_{\text{RF}} & p_{\text{XGB}} & p_{\text{BiLSTM}} & p_{\text{GRU}} \end{bmatrix}$$
