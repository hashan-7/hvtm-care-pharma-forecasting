# HVTM Care Pharma Forecasting

HVTM Care Pharma Forecasting is a machine learning based medical inventory demand forecasting system designed to predict future drug demand using historical pharmaceutical inventory data.

The system combines classical machine learning models, deep learning models, and a meta-learning approach to support smarter pharmacy stock planning and reduce inventory shortages or overstocking.

## Project Overview

This project includes:

- A web-based frontend dashboard
- A FastAPI backend service
- Drug demand prediction models
- Data preprocessing and feature engineering notebooks
- Model training, evaluation, and deployment notebooks
- Trained model files and prediction logic

## Main Features

- Monthly drug demand prediction
- Medical inventory data management
- Machine learning and deep learning based forecasting
- Model comparison and evaluation
- Web dashboard for user interaction
- Backend API for prediction and data handling
